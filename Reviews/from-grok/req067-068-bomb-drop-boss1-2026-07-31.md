## REQ-067: 전멸 폭탄 드롭 경로

### 원인

버튼·픽업·발동 파이프라인은 정상이었으나:

- 전 적 `bombDropWeight` 누락 → 파서 기본 **0**
- `dropTable.bombNoDropWeight` 미기입 → 기본 **100**
- `rewards.json`에 `bombStock` 없음  

→ 드롭 추첨이 영원히 "안 나옴".

### 설계 (스테이지당 기대 1~2 · 상한 3)

`bombNoDropWeight = 100` 고정. 중형·중간보스 가중, 잡몹은 0.

| 티어 | 대상 | bombDropWeight | P(drop) |
|---|---|---:|---:|
| 중간보스 | `mini_*` 5종 | **150** | **60%** |
| 중형/엘리트 | `zako_tank`, `elite_sine`, `guardian_sphere`, `shard_prism` | **25** | **20%** |
| 중형 사수 | turret×2, hive_tentacle, sentry, tumbler, brood, mortar, echo, void_moth, phase_disc | **6** | **5.7%** |
| 스테이지1 스크랩 시그니처 | `junk_roller` only | **4** | **3.8%** |
| 잡몹 | 나머지 zako/dart/wisp 등 | 0 | 0% |

**스테이지1 특수:** 세그 풀에 중형·엘리트가 없어 midboss + `junk_roller`만 기여.

### 스테이지별 폭탄 EV (kill-all · open+close 6seg + midboss)

### 보상 풀

파서 `type: "bombStock"` 지원 확인 (CODEX REQ-041).

```json
{
  "id": "bomb_stock_1",
  "type": "bombStock",
  "amount": 1,
  "weight": 2,
  "stageIndexMin": 1,
  "stageIndexMax": 99,
  "maxPerRun": 3
}
```

- stage1 풀 점유율 2/34 ≈ **5.9%** (slot 업과 동급 weight)
- `maxPerRun: 3`으로 보상만으로 스톡 채우는 경로 제한
- 3-choice 화면당 출현 기대 ≈ 0.1–0.2 (드롭 주 경로, 보상은 보험)
