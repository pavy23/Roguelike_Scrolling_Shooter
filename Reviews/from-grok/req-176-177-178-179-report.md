## REQ-176 — 레이저 시작점이 포대가 아님

### 원인

함저 서치 레이저 시절 잔재: `startOffsetY: 14.0` 은 **세로 빔이 화면 위 밖에서 내려오도록** 넣은 값.  
`aimsAtPlayer: true` 로 방향만 플레이어를 향해 돌아가도 **시작점은 포대에서 14wu 위**라 허공 발사가 됐다.

### 조치

| 파츠 | startOffset (구) | startOffset (신) |
|---|---|---|
| turret_c–f | (0, **14**) | (**0**, **0**) |
| turret_a/b | (−1.5, 0) | **유지** (포신 왼쪽 끝 ≈ halfWidth 1.5 — 이미 포구 근처) |

- `endOffset` 은 방향 벡터 유지 (조준 시 사거리 계산용, 길이는 Core가 화면 끝까지).
- 두께·주기·damage 변경 없음.

## REQ-179 — 2막 타이머를 안전장치로

### 배경

Core 변경: 소모전(2막)은 **함저 4문 전멸 시 즉시 3막**.  
`advanceAfterTicks` 는 포탑이 닿지 않는 자리 등에 선 경우의 **교착 방지**만 남김.

구 값 600t = 10s 는 pure ST 함저 녹이기(9600@720 ≈ 13.3s)보다도 짧아 **타이머가 정상 경로**가 됐다.

### 조치

| 항목 | 구 | 신 |
|---|---:|---:|
| `hull.advanceAfterTicks` | 600 (10s) | **4800 (80s)** |

- pure ST 함저 전멸 ≈ 13.3s 의 **약 6배**
- 구 타이머의 **8배**
- 회피 세금 2~3× 로 잡아도 보통 클리어는 40s 전후 → 80s 안전장치는 "다 부숴야 넘어간다"를 실제 규칙으로 둔다.

### BalanceSim 정합 (GROK 소유 스크립트)

- `WarshipAttritionTicks` 600 → **4800**
- `WarshipDeckTurretHp` 700 → **1600** (REQ-168×2 + REQ-177)
- `WarshipKeelTurretHp` 1200 → **2400**
- 함저 개수 게이트 2 → **4** (REQ-168 잔재 정리)
- hull partIds `c,d` → **`c,d,e,f`**
- travel tick 밴드 90..150 → hull 180..300 / bow 120..240 (REQ-168 잔재)
- **벽시계 모델**: attrition 을 타이머 합산에서 빼고 **함저 전멸 ST** 로 계산.  
  안전 타이머 < 3× 함저 melt 이면 FAIL 179 추가.

결과 (본 작업 관련):

```
warship parts=8 sum=44400 maxHp=44400 engine=2000 turrets=6@12800 core=29600
TTK@reach720: pureST=61.7s full=23.6s wall≈64.7s (warn3.0+eng7.2+attr13.3+core41.1)
PASS: REQ-111 warship TTK + ghost review.
```
