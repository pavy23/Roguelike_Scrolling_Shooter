## REQ-160 — 하이브 마지막 패턴: 발사 후 유도 제거

### 원인

최종 페이즈(`hpThreshold: 0.333`)는 `projectileKind: mine` + `signaturePatternId: brood`.

| 경로 | 동작 | 체감 |
|---|---|---|
| `UpdateMineProjectile` | 예고 종료 시 **플레이어 방향 가속을 한 번 고정** | 발사(예고) 시점 조준 — 의도된 직진 가속 |
| `TurnEnemyProjectileTowardPlayer` | brood 시 `signatureHomingTurnLutSlotsPerTick`만큼 **매 틱 선회** | 느린 탄이 끝까지 따라옴 → **못 피함** |

느린 탄 자체(mineAcceleration 2, bulletSpeed 2.5)는 REQ-147/151에서 이미 회피 가능 대역. 문제는 **속도가 아니라 무한 유도**.

### 데이터 변경 (최종 페이즈만)

| 필드 | 전 | 후 | 근거 |
|---|---|---|---|
| `signaturePatternId` | `brood` | **삭제** | brood 시 기뢰에 homing turn이 붙음 |
| `signatureSpawnEnemyId` | `hive_tentacle` | **삭제** | brood 제거에 동반 |
| `signatureHomingTurnLutSlotsPerTick` | 1 | **삭제** | 비행 중 선회 0 |
| mine / spiral / ways / accel / telegraph | 유지 | 유지 | **속도 손대지 않음** (사람 지시) |

예고 종료 시 조준 고정 → 직진 가속만 남는다. P1(중간, `hpThreshold: 0.667`) brood·호밍은 유지(이번 범위 밖).

### Core 한계 / 요청

`BossPhase` 생성 시:

```
Brood signatures require a spawn enemy id and positive homing turn rate.
```

→ `signatureHomingTurnLutSlotsPerTick: 0` 은 **파서가 거절**한다.  
데이터만으로 “텐타클 스폰은 유지 + 유도만 0”을 할 수 없다.

**CODEX 요청** (`Reviews/from-grok/requests.md`에도 요약 가능):

1. Brood 시 `signatureHomingTurnLutSlotsPerTick` **0 허용** (0 = 비행 중 선회 없음, 스폰만).
2. 또는 기뢰 호밍을 signature와 분리한 필드 (예: `mineHomingTurnLutSlotsPerTick`).

0 허용 후 최종 페이즈에 brood 스폰을 복구할 수 있다. 현재는 최종 페이즈 텐타클 스폰이 빠지고, 중간 페이즈 스폰만 남는다.

## REQ-161 — 전함 2막: 가운데 쪽 위 + 수직 레이저

### 1막 유지

`stern` (midbossGate): `anchorOffsetY: -4.5`, 파츠·레이저 **무변경**.  
`holdX: 12.0` 유지 → 1막 정박 X 동일.

### 가로: 소모전 왼쪽 드리프트 축소

소모전 스크롤 한계(WorldX 최소)는 Core가 **미래 파츠(코어 포함)** 기준으로 잡는다.  
정박 한계 자체는 데이터로 못 옮기므로, **한계에 닿기 전에 막을 끝내도록** 흘러가는 속도를 줄였다.

| 필드 | 전 | 후 | 근거 |
|---|---:|---:|---|
| `originX` | 24.0 | **18.0** | hold까지 거리 = `holdX` 대비 **6 wu** (구 12). 접근 시간 유지용 |
| `scrollSpeedPerSecond` | 3.0 | **1.5** | 소모전 10s × 1.5 = **15 wu** 이동. 한계(~21 wu)에 못 미침 → 막 종료 WorldX ≈ **−3** (구 ≈ **−9**) |
| `holdX` | 12.0 | 12.0 | 1막 정박 위치 고정 |

접근 시간: 6 wu / 1.5 wu/s = **4.0s** — 구(12/3=4.0s)와 동일.  
1막은 같은 hold에 같은 시간에 도착하고, **2막만** 덜 왼쪽으로 흐른다.

### 세로: 가운데 쪽 위

| 필드 | 전 | 후 | 근거 |
|---|---:|---:|---|
| `hull.anchorOffsetY` | +5.0 | **+3.0** | 위로 가되 덜. 함저 포탑 중심 Y: c **−2.125**, d **−1.3125** (구 −0.125 / +0.6875) — 눈높이보다 약간 아래·중앙 밴드 |
| `anchorTravelTicks` | 120 | 120 | 2.0s 상승 연출 유지 |

함체 실루엣(정박 후): Y ∈ **[−5.5, +11.5]** (구 [−3.5, +13.5]). 위 돌출 완화, 여전히 1막(−4.5)보다 위.

### 레이저: 위에서 아래로

함저 `turret_c` / `turret_d` — 구 가로 빔(`endOffsetX: -28`)은 함체가 위에 있으면 **화면 밖 가로 사격**.  
**수직 관통**으로 교체 (플레이필드 halfH ≈ 11.25 기준 startY+14 → endY−16).

| | turret_c | turret_d |
|---|---|---|
| cycle / interval | **200** | **220** (위상 어긋남) |
| telegraph | **48** (0.80s) | **52** (0.87s) |
| sustain | 50 | 50 |
| 축 | (0, +14) → (0, −16) | 동일 수직 |
| fullHalfWidth | **0.875** | **0.875** |
| damage | **2** (함저 강화 유지) | **2** |

lifetime c: 48+8+50+12=118 ≤ 200, d: 52+8+50+12=122 ≤ 220 — 사이클 비중첩.

주기적으로 세로 기둥이 내려 꽂히므로, 함체가 위에 있어도 플레이 영역을 가로지른다. 저속 기체(이속 ~10.4) 기준 텔 0.8s ≈ 8u 횡이동 — 두께 1.75u 대비 회피 여유.

## REQ-162 — 히든 보스 시그니처 가시성

### 레비아탄 — 중앙 극태 레일

`railgun` P3 레이저만 손댐 (다른 페이즈·파츠 무변경).

| 필드 | 전 | 후 | 근거 |
|---|---:|---:|---|
| `fullHalfWidth` | 2.5 | **3.75** | 두께 **7.5u** — 시그니처로 읽히는 굵기. 플레이필드 높이 22.5의 ~1/3 |
| `thinHalfWidth` | 0.25 | **0.75** | 차징 라인도 눈에 띄게 |
| `telegraphTicks` | 150 | **180** | **3.0s** 예고. bulwark L0 이속 10.4 → ~31u 이동 ≫ 빔 반폭 3.75 |
| `firingTicks` | 10 | **12** | 점화 가독 |
| `sustainTicks` | 72 | **108** | **1.8s** 지속 — “한 방 굵은 빔” 존재감 |
| `dissipateTicks` | 20 | **24** | 페이드 |
| `cycle` / `interval` | 300 | **360** | lifetime 180+12+108+24=**324** ≤ 360 |
| `endOffsetX` | −27.4 | **−32.0** | holdX 9 + 포구 −3.9 기준 월드 끝(~−20)을 **확실히** 통과 |

난이도: 히든답게 굵고 길지만, 3초 예고로 **피한다**. “못 피한다” 계열(예고 없음 / 회피 공간 없음)과 반대.

BalanceSim 게이트: `fullHalfW ∈ [1.2, 4.0]`, `endOffsetX ≤ −30` 로 상향 (Tools/BalanceSim).

### 브루드마더 — 산발 레이저 밀도·길이

P3 파츠 레이저: **3줄기 → 5줄기**, 길이 **화면 밖까지**, 각도 **균등 분배**.

| 파츠 | 역할 | endOffset | fullHalfW | cycle/tel |

| tentacle_left | 상단 줄기 | (−34, **+9**) | 1.25 | 320 / 150 |
| sac_left | 중상 (신규 레이저) | (−34, **+4.5**) | 1.25 | 300 / 140 |
| maw | 중앙 주력 | (−34, **0**) | **1.75** | 280 / 150 |
| sac_right | 중하 (신규 레이저) | (−34, **−4.5**) | 1.25 | 310 / 145 |
| tentacle_right | 하단 줄기 | (−34, **−9**) | 1.25 | 340 / 160 |
| sac_lower | 산란 유지 | spawn 600t | — | — |

**길이**: endOffsetX **−26 → −34**.  
maw@holdX≈9 기준 구 end 월드 X ≈ −17 (halfW 20 안쪽에서 끊김 = “짜침”). 신 end ≈ −25 이하 → **왼쪽 화면 밖**.

sac_left/right P3 스폰은 레이저로 교체(개수 확보). 산란 감은 `sac_lower` 1포트 유지.
