# 히든 보스 파츠 앵커 — 확정 (2026-08-02, RENDERER/Opus)

보스 리디자인 스펙 `Reviews/from-claude/boss-redesign-2026-08-03.md`의 히든 3막화를 위한
**스프라이트 확정본 기준 좌표 단일 소스**. GROK 수치 테이블(REQ-116)과 CODEX 파츠 정의(REQ-115a)는
이 문서의 좌표를 참조한다. 여기 없는 값(HP·간격·탄속)은 GROK 소관.

## 확정 스프라이트

| 보스 | 파일 | 크기 | 색수 | 채택 |
|---|---|---|---|---|
| Leviathan | `art-input/boss_leviathan.png` | 320×336 RGBA | 31 | 시안 C (다관절 기계 거신) |
| Broodmother | `art-input/boss_broodmother.png` | 320×336 RGBA | 31 | v3 |

- PixelLab Pro(`/v2/generate-image-v2`) 생성 → 하드 알파(임계 128) + 미디언컷 32색 이내.
- **아직 `Assets/` 임포트도 씬 배선도 하지 않았다.** 다음 리디자인 통합 패스에서 처리한다.
- 앵커 시각 검증 시트:
  `scratchpad/art-samples-v3/03_part_anchors_final.png` (파츠 박스 + 머즐 + holdX 9.0 프레임)

## 좌표계 규약

- **원점 = 스프라이트 중심**, +X 오른쪽 / +Y 위쪽. `waves.json`의 `offsetX/offsetY`와 동일한 규약.
- **PPU 16**. 캔버스 320×336 px = **20.0 × 21.0 world unit**.
- 플레이어는 화면 왼쪽, 보스는 오른쪽. 두 보스 모두 **좌향**(포신·아가리가 왼쪽을 본다).
- 카메라 40.0 × 22.5 world. 화면 오른쪽 끝 = world x +20.0, 중앙 = x 0.

## 히트박스 / holdX

| 항목 | Leviathan (C) | Broodmother (v3) |
|---|---|---|
| 그림 실제 콘텐츠 bbox | x −9.81 … +9.75, y −9.94 … +10.06 | x −9.25 … +9.25, y −9.50 … +9.13 |
| 권장 `halfWidth` | **9.8** | **9.25** |
| 권장 `halfHeight` | **10.0** | **9.3** |
| 권장 본체 y 보정 | +0.06 (무시 가능) | −0.19 (무시 가능) |
| 권장 `holdX` | **9.0** | **9.0** |

- 스펙의 `halfWidth 9~10 / halfHeight 10.5`를 그대로 써도 되지만, 위 값이 그림과 정확히 맞는다.
  10.5를 쓰면 두 보스 모두 하단에 1~1.2 unit의 빈 판정이 생긴다.
- **`holdX 12.0`은 못 쓴다.** halfWidth 10 기준 함체 오른쪽 끝이 x +22 → 화면 밖(+20)으로 2 unit 잘린다.
  `holdX 9.0`이면 함체가 x −1.0 … +19.0을 점유해 전부 화면 안이면서 **화면 오른쪽 절반을 정확히 차지**한다.
  (검증 이미지: `03_part_anchors_final.png` 하단 프레임)

## Leviathan (시안 C — 다관절 기계 거신)

조형: 스컬 카울 + 적색 옵틱 밴드, 왕관처럼 뻗은 포탑 스파인, **노출된 세그먼트 척추**와 적색 동력선,
힌지 늑골이 레일건 위로 물려 있고 그 사이에 코어 퍼니스. 좌측에 절지 블레이드 리브 2쌍.

> **비대칭 주의**: 척추 아크가 **오른쪽으로 휜다**. 그래서 `rear_engine`(방열 핀 스택)은 x **+8.4**,
> `shield_emitter`(링 코일)는 x **+2.0 / y −7.8**로 축에서 벗어나 있다. A·B 시안이나 기존 좌우대칭
> 전제로 오프셋을 잡으면 그림과 어긋난다.

**2막 참수 레일건 `bossLaser` 좌표** — 기존 레이저 축 재사용 시:

```
startOffsetX = -6.5      // 포구
startOffsetY =  1.4
endOffsetX   = -30.0     // holdX 9.0 기준 화면 왼쪽 끝(월드 -20)은 보스 기준 -29. 여유 포함
endOffsetY   =  1.4      // 수평 빔 (기울기 0)
```

`endOffsetX`를 기존값 −20.0으로 두면 보스 기준 −20 = 월드 −11에서 빔이 끊겨 화면을 관통하지 못한다.
포구가 이미 −6.5만큼 왼쪽이므로 **−30 이하**여야 한다.
`fullHalfWidth`는 스펙의 "극태빔"에 맞춰 기존 St5(0.625)보다 크게 — 1.2~1.6 권장(그림상 포신 구경이
halfHeight 0.8이므로 빔이 포신보다 굵어야 극태로 읽힌다). 최종 수치는 GROK 판단.

2막 낙하물(포탑 잔해)은 스파인 포구 4좌표를 그대로 스폰 원점으로 쓰면 된다.
3막 기뢰 살포 원점은 `core` 중심 (+2.4, +1.0).

## Broodmother (v3)

조형: 상단 키틴 아가리 + 시안 발광 이음선, 중앙 늑골 안의 심장, 좌우 낭, 양 끝까지 뻗은 가시 촉수.
좌우 대칭이라 오프셋 부호만 뒤집으면 된다.
