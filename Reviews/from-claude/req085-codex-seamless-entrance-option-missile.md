# REQ-085 (CODEX): 보스 등장 연속화 재수정 + 옵션 미사일 (7차 피드백)

너는 CODEX = SIMULATION 담당이다. 작업 디렉토리 wt-sim, 시작 전 `git merge main`.

## A. 보스/중간보스 등장이 "여전히 끊긴다" (사람 재교정)

REQ-082 A의 "빈 전장 60틱 정적"이 오히려 흐름을 끊는 느낌을 만들었다. 사람 지시:
**"중간에 자연스럽게 화면 끝에서 출현하는 것으로 하자."**

수정:
1. `BossPostClearDelayTicks`(60틱 빈 전장 대기) **제거** — 보스는 필드가 비기를 기다리지
   않는다. 살아 있는 졸개와 **공존한 채** 화면 우측 밖에서 활강 등장한다.
2. 스폰 억제 리드는 유지하되 90 → **40틱**으로 줄여라 (등장 직전 신규 웨이브만 막는 용도).
3. 잔여 졸개의 자연 퇴장(즉시 삭제 금지) 로직은 그대로 둔다 — 등장과 병행될 뿐이다.
4. REQ-082에서 넣은 시간제한 60틱 연장 보상은 정적이 사라지므로 **롤백**해라.
5. 중간보스·스테이지 보스·히든 보스 모두 동일.

## B. 미사일이 옵션에서도 발사 (사람 지정)

주무기 볼리가 옵션에서 미러되듯, **미사일 볼리도 각 옵션 위치에서 미러**로 나가게 하라.

- 발사 순서 결정론: 본체 미사일 → 옵션 index 오름차순. 탄 예산(MaxBullets) 초과 시
  기존 규칙대로 뒤가 잘린다.
- 옵션 미사일 데미지는 본체의 일정 비율로 — `weapons.json`에
  `optionMissileDamagePercent`(선택 필드, 기본 100) 훅을 추가해라. 실제 값은 GROK이
  정한다 (옵션 6기 × 미사일이면 화력 폭증이므로 100 미만이 유력).
- 유도 미사일 타깃 선정도 기존 결정론 규칙 재사용.
