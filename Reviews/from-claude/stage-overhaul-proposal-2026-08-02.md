# 스테이지 대개편 + 크레딧 경제 설계안 (2026-08-02, 사람 검토 대기)

벤치마킹 근거: Gradius II~V(shmuplations 개발자 인터뷰), R-Type/Delta/Final, Darius Gaiden/G-Darius,
Thunder Force IV, Einhänder, ZeroRanger, Drainus, Devil Engine, Hades/Dead Cells(메타 경제).
상세 조사 원문은 오케스트레이터 세션 기록 참조.

## 0. 설계 원칙 (조사에서 추출)

1. **구간 경계는 "3종 세트"로 신호한다**: 파티클(날씨) + 틴트(팔레트) + 스크롤 속도.
   아트 비용 0으로 "구간이 바뀌었다"를 몸으로 알게 하는 최저비용 문법 (Metal Slug X · Gradius 전통).
2. **중간보스 격파 = 세계 전환 이벤트**: 격파 순간에 매질/조명/배경 전환을 겹쳐
   경계를 서사로 만든다 (Darius 수면 돌파, R-Type 함내 진입).
3. **후반 = 지형 잠식**: `traversableLaneMasks` 7→3→2 계단 축소 (Gradius III 식물면
   개발자 증언 "깊이 들어갈수록 잠식"). 이미 스키마에 있는 필드 — 데이터만으로 성립.
4. **보스 직전 밸리**: 스폰 공백 120~180틱 + WARNING. 완급 없는 긴장은 소음이다.
5. **스테이지당 시그니처 기믹 1개**: "그 스테이지 하면 떠오르는 것"을 하나만, 확실하게.
6. **배경은 스테이지당 1.5세트**: 풀 4레이어 1세트 + (원경 교체 1장 · 하늘 2종 ·
   전경 실루엣 1층 · 파티클 3~4종). AI 생성 시 팔레트 15~24색 고정 → 틴트/스왑 성립 조건.

## 1. 스테이지별 설계 (4구간: 전반 → 중간보스 → 후반 → 보스)

### St1 고철 폐선장 — "출격의 설렘" (BGM 경쾌)
- **시그니처: 고철 방패** (Gradius V 소행성 문법) — 파괴 가능 고철 덩어리가 **적탄을 차단**.
  쏘면 엄폐물이 사라진다 — "쏘지 않는 것이 방어"를 1스테이지에서 가르친다.
- 전반: 오픈 물량전. 원경에 폐함대 실루엣(포섀도잉). 낮 팔레트.
- 중간보스: 고철 크레인 메카. 격파 시 **고철더미 붕괴 + dusk 틴트 lerp + 재(灰) 파티클**.
- 후반: 고철 협곡 — 레인 7→3 잠식 + 파괴벽 파밍. 스크롤 1.5배 스파이크 1회(짧게).
- 보스: 용광로 앞 — 배경 암색 + 적색 발광 조명. 기존 JunkToss 시그니처 유지.

### St2 생체 군체 — "아름답지만 낯선" (BGM 잔잔)
- **시그니처: 재생 세포벽** (Gradius III Cell + Salamander) — 쏘면 파이고 수 초 후 재생하는
  유기벽. 화력 = 이동 공간. 결정론 틱 그리드와 궁합 최상.
- 전반: 군체 외피 — 오픈, 포자 부유물 파티클, 밝은 유기 팔레트.
- 중간보스: 격파 시 **체내 진입** — 하늘 레이어 제거 + 녹색 틴트 + BGM 로우패스(수중 문법).
- 후반: 세포벽 굴착 통로 — 재생벽 사이를 파고 나아감. 레인 잠식 병행.
- 보스: 심장부 — 배경 맥동(스케일 펄스), 어둠 + 생체발광 파티클. Brood 시그니처 유지.

### St3 기계 요새 — "쫓기는 긴장" (BGM 긴장 A·드라이브)
- **시그니처: 스테이지=거대 전함** (R-Type 3면 문법) — **중간보스+후반을 통째로
  거대 전함 1척에 할당**. WARNING과 함께 등장한 전함의 함미 추진기 파괴(=중간보스),
  이후 후반 전체가 함체 위 포탑 라인 일주. 기존 멀티파트 보스(`parts[]`) 구조 재사용.
- 전반: 요새 외곽 편대전. 원경에 전함 실루엣이 소형으로 통과(예고).
- 경계: WARNING + 셰이크 + 적색 틴트 스냅(Darius 요새 진입 문법).
- 후반: 함체 지형 — 포탑=지형=적. 파괴한 포탑 수에 따라 보스전 개막 탄막 밀도 감소(분기 보상).
- 보스: 함수 코어룸(하늘 제거, 함내 조명). LaserGrid 시그니처 — 이번 레이저 가시성
  개편(예고 점멸 + 원점 글로우)이 여기서 빛난다.

### St4 성운 폭풍 — "숨죽이는 긴장" (BGM 긴장 B·서스펜스)
- **시그니처: 어둠 + 서치라이트** (Einhänder 1면 문법) — 기존 visionObscured 기믹 위에
  회전 탐조등(프레젠테이션 전용, URP 2D 라이트). 적 탐조등 원뿔에 걸리면 조준탄이 집중된다.
- 전반: 성운 표층 — 보라 팔레트 + 안개 레이어 1장(별도 속도 스크롤).
- 중간보스: 격파 시 **뇌운 진입** — 전역 암전(Global 0.3), 낙뢰 섬광이 0.2초씩 화면을 밝힘.
- 후반: 서치라이트 회피 구간. 낙뢰 예고(Salamander 프로미넌스 문법: 예고선 → 아크).
- 보스: **폭풍의 눈** — 급격히 맑아지는 역설적 정적(밸리) → Lightning 티탄 등장.

### St5 적의 코어 — "비장한 장엄" (BGM 웅장)
- **시그니처: 타임루프 고스트** (Gradius V 2/8면 문법) — **이번 런의 St1 입력 기록을
  고스트 기체로 재생해 협공**. 결정론 고정틱 + 입력 기록 아키텍처 보유 시 구현이 거의
  공짜인데 효과는 시리즈 최고 명장면급. 우리 아키텍처의 존재 이유를 보여주는 기믹.
- 전반: 코어 외곽 — 네온 가산 글로우, 고속 스크램블 스파이크 1회(짧게).
- 중간보스: mini_core. 격파 시 최심부 게이트 개방 연출.
- 후반: 고스트 협공 구간 + 레인 잠식 최대(7→2). 배경의 거대 코어가 점점 커진다(접근감).
- 보스: 회전 프리즘 코어. 픽카르디 장엄 BGM과 함께 최종전.

## 2. 배경 구간 차별화 — 공통 파이프라인

- Presentation 전용 `SectionTheme`(팔레트 틴트 · 레이어 on/off · 패럴랙스 배율 ·
  파티클 · 2D 라이트) 를 구간 진입 이벤트에서 20~30초 lerp 블렌드.
- Core가 소유하는 것은 `scrollSpeed` 하나뿐 — 결정론 무영향.
- 아트 발주(스테이지당): 원경 교체 1장, 하늘 그레이디언트 2종, 전경 실루엣(단색) 1층,
  랜드마크 스프라이트 1개(난파선/거대 안테나류 — 반복 배경 착시 해소), 파티클 3~4종.
  AI 파이프라인 팔레트 15~24색 고정.
- 5스테이지 × 4구간 = **20룩을 배경 7.5세트 분량으로** 커버.

## 3. 크레딧 경제 설계 (현재: 기체 해금뿐)

핵심 채택: **ZeroRanger식 "컨티뉴 = 판돈" 경제** — 파워 인플레 없이 누적 플레이에 의미.

| 순위 | 싱크 | 내용 | 근거 |
|---|---|---|---|
| P1-A | **컨티뉴 적립** | 크레딧으로 컨티뉴 구매·적립(상한 8). 사용 시 그 런 점수 0 리셋(보드 공정 유지) | ZeroRanger |
| P1-B | **최종전 판돈화** | 최종보스전이 보유 컨티뉴를 라이프로 환산하고 **전량 회수**. 이기면 대승, 져도 세이브는 유지(ZR보다 완화) | ZeroRanger TLB |
| P1-C | **보상 풀 확장** | 크레딧으로 보상 카드 풀에 신규 카드 해금(직접 강화 아님 — 파워크리프 최소) | Dead Cells |
| P2-A | **대체 로드아웃** | 기체별 시작 무기 변형 해금(수평 — 성능이 아니라 이질성에 과금) | DariusBurst CS |
| P2-B | **치장 상점** | 기체 팔레트 스킨 · 탄 색상 · 타이틀 BGM 선택. 무한히 팔 수 있는 가장 안전한 싱크 | Blue Revolver |
| P2-C | **코덱스** | 적/보스 도감 + 패턴 해설. 조우 횟수 해금과 병행 | Hades Codex |
| P3 | **도전 모드 해금** | 보스 러시 · 하드 난이도 — 실력 달성 or 구매 이중 경로 | Jamestown |

기존 SPARTAN 계약(gauge/option/shield 금지)은 이미 Hades Pact(heat)의 페널티 모듈 —
P2 이후 "고계약 전용 치장 보상"만 붙이면 heat 시스템이 완성된다.

## 4. 구현 단계 제안 (승인 시)

| 단계 | 내용 | 담당 | 규모 |
|---|---|---|---|
| A | 구간 스키마(섹션 마커·midbossOutcome·잠식 규칙) + 시그니처 기믹 Core 축 4종(고철 방패·재생벽·서치라이트 조준 규칙·고스트 재생) | CODEX | 대 (REQ 2~3개 분할) |
| B | 스테이지별 세그먼트/웨이브 재설계 + 밸런스 | GROK | 대 |
| C | SectionTheme 전환 시스템 + 배경 0.5세트×5 아트 생성 + 연출 | Opus + ArtGen | 대 |
| D | 크레딧 P1(컨티뉴 경제 + 풀 확장) | CODEX+Opus | 중 |
| E | 크레딧 P2(로드아웃·치장·코덱스) | 분할 | 중 |

권장 착수 순서: A+B 병렬 → C → 테스터 → D → E.
St3(거대 전함)과 St5(고스트)가 체감 임팩트 최대 — 시연 우선순위로 추천.
